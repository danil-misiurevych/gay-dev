# Assets

```
source/   source files (.blend, .fig, .psd) — not part of the build
models/   .glb exports, ready to use in the game
ui/       2D graphics: icons, backgrounds for interface elements
```

Requirements for models: [`../docs/ART-SPEC.md`](../docs/ART-SPEC.md).
Requirements for the 2D layer: [`../docs/UI-SPEC.md`](../docs/UI-SPEC.md).

The `source/` directory is deliberately kept in the repo despite its size — a
model's source file that nobody but its author has is effectively lost at the
first change of hands in the team.
