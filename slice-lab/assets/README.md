# Assety

```
source/   pliki źródłowe (.blend, .fig, .psd) — nie trafiają do builda
models/   eksporty .glb gotowe do użycia w grze
ui/       grafika 2D: ikony, tła elementów interfejsu
```

Wymagania dla modeli: [`../docs/ART-SPEC.md`](../docs/ART-SPEC.md).
Wymagania dla warstwy 2D: [`../docs/UI-SPEC.md`](../docs/UI-SPEC.md).

Katalog `source/` jest celowo w repo mimo rozmiaru — plik źródłowy modelu,
którego nikt poza autorem nie ma, jest w praktyce stracony przy pierwszej
zmianie w zespole.
